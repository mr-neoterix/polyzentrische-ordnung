% Pandoc-Vorlage für das Manuskript „Die polyzentrische Ordnung“.
%
% Gesetzt wird mit LuaLaTeX. Die Vorlage ersetzt die mitgelieferte Vorlage
% von Pandoc absichtlich vollständig: Der Text ist reine Prosa ohne Formeln,
% Tabellen, Bilder und Listen, deshalb kommt der Satz mit wenigen Paketen
% aus – das hält die Installation klein und den Lauf schnell.

% Gesetzt wird zweiseitig: Die erste Seite ist eine rechte, danach wechseln
% sich linke und rechte Seiten ab. Daran hängen drei Dinge – der Bundsteg
% (innen mehr Rand als außen), die Seite des Kolumnentitels und der
% Seitenzahl (beide wechseln mit) und die Regel, dass Teile und Kapitel auf
% einer rechten Seite anfangen. Eingeschobene Leerseiten bleiben ganz leer,
% ohne Kolumnentitel und ohne Zahl.

  fontsize=10pt,
  paper=148mm:210mm,

  open=right,
  cleardoublepage=empty,
  parskip=false,
]{scrbook}

% Buchformat 14,8 × 21,0 cm. Der Satzspiegel ist gegenüber dem früheren
% A4-Stand mitgeschrumpft: 108 mm Zeilenbreite tragen bei 10 pt Pagella rund
% zweiundsechzig Zeichen und damit eine noch lesbare Zeile; unten steht mehr
% Rand als oben, damit die Seite nicht kippt. Die Zeichenzahl stammt aus der
% Pagella-Zeit und ist an Alegreya nicht nachgezählt; wer am Satzspiegel
% dreht, zählt sie vorher am gesetzten Bogen nach.
%
% Seit dem zweiseitigen Satz heißen die seitlichen Ränder nicht mehr links
% und rechts, sondern innen und außen, und sie sind ungleich: Der Bund
% schluckt einen Teil des inneren Randes, also bekommt er ihn zugelegt.
% Zusammen bleiben es dieselben 40 mm, die Zeilenbreite also dieselben
% 108 mm; nur der Textblock rückt auf jeder Seite ein Stück von der Mitte
% des Bogens weg.
\usepackage[
  paperwidth=148mm, paperheight=210mm,
  twoside=true,
  top=18mm, bottom=22mm, inner=22mm, outer=18mm,
  headsep=6mm, footskip=12mm,
]{geometry}

% --------------------------------------------------------------------------
% Schrift
% --------------------------------------------------------------------------
% Alegreya (Huerta Tipográfica, Juan Pablo del Peral) ist für den
% Literatursatz entworfen. Den Ausschlag gab ihre Kursive: Dieses Buch
% verbietet sich Listen und führt jede Aufzählung als kursives Inline-Label
% – gut zweitausend kursive Auszeichnungen, davon rund fünfhundert solche
% Labels. Eine Kursive, die sich von der Geraden kaum absetzt, träfe es
% darum härter als gewöhnliche Prosa.
%
% Die Schnitte liegen im Verzeichnis unter `satz/schriften/` und nicht im
% TeX-Baum. Das kostet gut ein Megabyte und spart dem Bauläufer ein Paket
% von 630 MB, das er sonst für fünf Dateien einspielen müsste; zugleich
% setzt jeder Rechner mit denselben Schnitten, ohne dass eine
% Schriftverwaltung mitspielen muss. Die Lizenz (SIL Open Font License)
% liegt als `OFL.txt` daneben und gehört bei jeder Weitergabe dazu.
%
% Den Pfad reicht das Satzskript als Pandoc-Variable herein. Fehlt sie,
% sucht LuaTeX wie zuvor im TeX-Baum – dann muss Alegreya dort liegen.
%
% Die Kapitälchen sind der Grund für die vorletzte Zeile. Alegreya führt sie
% als eigene Familie (AlegreyaSC) und nicht als Merkmal der Grundschrift;
% ohne die ausdrückliche Zuweisung bekäme \scshape stillschweigend Gemeine,
% und das träfe die Kapitelmarke und den Belege-Kopf jedes der siebenund-
% zwanzig Kapitel, ohne dass der Lauf etwas meldete. Beide Stellen setzen
% aufrechte Kapitälchen; ein Schnitt genügt deshalb.

]

% Der Kolumnentitel steht innen, die Seitenzahl außen – und beide wechseln
% mit der Seite: Auf der linken Seite liegt außen links, auf der rechten
% außen rechts. Das besorgen \ihead und \ohead von selbst, sobald zweiseitig
% gesetzt wird; sie meinen innen und außen, nicht links und rechts.
%
% Der Kolumnentitel sagt dabei auf jeder Seite etwas anderes, und das ist
% der eigentliche Gewinn des zweiseitigen Satzes: Links steht das Kapitel,
% rechts der Abschnitt – vom Allgemeinen zum Besonderen, wie das
% aufgeschlagene Buch gelesen wird. Zwei Marken tragen das. \kapitel setzt
% beide auf den Kapiteltitel, jeder Abschnitt überschreibt danach die
% rechte; die linke bleibt bis zum nächsten Kapitel stehen.

\usepackage{scrlayer-scrpage}
\clearpairofpagestyles
\setkomafont{pagehead}{\normalfont\footnotesize\itshape\color{leise}}
\setkomafont{pagenumber}{\normalfont\footnotesize\color{leise}}
\ihead{\headmark}
\ohead{\pagemark}
% Das eckige Argument gilt für den Seitenstil „plain“: Auf Kapitelanfängen
% steht kein Kolumnentitel, die Seitenzahl aber sehr wohl – sonst verliert
% man beim Blättern die Orientierung. Sie steht dort mittig und braucht
% deshalb als einzige nicht mit der Seite zu wechseln.
\cfoot[\pagemark]{}
\pagestyle{scrheadings}

% Ein Kapitelanfang: Bezeichnung als Zeile darüber, Titel darunter. Kapitel
% fangen auf einer rechten Seite an; wo eine linke frei bleibt, bleibt sie
% ganz frei.
\newcommand{\kapitel}[2]{%
  \cleardoublepage
  \phantomsection
  \thispagestyle{plain}%
  \vspace*{0.08\textheight}%
  \begingroup
    \raggedright
    {\normalfont\large\scshape\color{akzent}#1\par}%
    \vspace{0.7em}%
    {\normalfont\Huge\bfseries#2\par}%
  \endgroup
  \vspace{2.4em}%
  \addcontentsline{toc}{chapter}{#1 – #2}%
  \markboth{#2}{#2}%
  \@afterindentfalse\@afterheading
}

% Eine Teilseite: allein auf einer rechten Seite, ohne Kolumnentitel; die
% linke Seite dahinter bleibt frei, damit das erste Kapitel des Teils wieder
% rechts anfängt.
\newcommand{\teil}[1]{%
  \cleardoublepage
  \phantomsection
  \thispagestyle{empty}%
  \null\vspace*{0.24\textheight}%
  \begingroup
    \centering
    {\normalfont\LARGE\bfseries\color{akzent}#1\par}%
  \endgroup
  \addcontentsline{toc}{part}{#1}%
  \markboth{#1}{#1}%
  \clearpage
}

% Ein Vorspannabschnitt: wie ein Kapitel, aber schlichter.
\newcommand{\vorspann}[1]{%
  \cleardoublepage
  \phantomsection
  \thispagestyle{plain}%
  \vspace*{0.04\textheight}%
  \begingroup
    \raggedright
    {\normalfont\LARGE\bfseries#1\par}%
  \endgroup
  \vspace{1.6em}%
  \addcontentsline{toc}{chapter}{#1}%
  \markboth{#1}{#1}%
  \@afterindentfalse\@afterheading
}

\newcommand{\hauptteil}{\cleardoublepage\mainmatter}

% Der Belegapparat am Kapitelende: kleiner gesetzt, mit Abstand statt
% Einzug, damit er als Apparat und nicht als Fließtext gelesen wird.
\newcounter{belegblock}
\newcommand{\belegeanfang}{%
  \par\bigskip
  \stepcounter{belegblock}%
  \pdfbookmark[1]{Belege}{belege.\thebelegblock}%
  % Strich und „Belege“ bilden einen einzigen zweizeiligen Absatz, nicht zwei
  % durch \nobreak verbundene Einzeiler. So kann der Strich nie das letzte
  % Element einer Seite werden: Der Umbruch zwischen den beiden Zeilen ist durch
  % \clubpenalty und \widowpenalty (beide 10000, siehe oben) gesperrt – dieselbe
  % Sperre, die Schusterjungen und Hurenkinder verhindert –, verstärkt durch das
  % \\* des Zeilenumbruchs. Zwei durch \nobreak getrennte Absätze taten das
  % nicht zuverlässig: Dort fiel der Seitenumbruch bisweilen auf die Glue nach
  % dem Strich und ließ ihn allein am Fuß der Seite zurück. Das \hfill\null füllt
  % die kurze Strichzeile, damit sie nicht als „underfull“ gemeldet wird.
  \noindent\textcolor{leise}{\rule{0.3\linewidth}{0.4pt}}\hfill\null\\*[0.9em]%
  {\normalfont\scshape\color{akzent}Belege}\par
  \nobreak\vspace{0.5em}%
  \begingroup
    \small
    \setlength{\parindent}{0pt}%
    \setlength{\parskip}{0.55em}%
}
\newcommand{\belegeende}{\par\endgroup}
